# Crayons Loop Studio

Internal AI content creation and production engine for Crayons Loop.

## Product contract

Crayons Loop Studio turns an idea into publish-ready content and manages the lifecycle through distribution, growth and revenue.

Core loop:

`IDEA -> CREATE -> PRODUCE -> QA -> PUBLISH -> VERIFY -> GROW -> MONETIZE`

## Execution law

1. Reuse existing verified repository capabilities first.
2. Free-first: local/open-source/free official capabilities before paid services.
3. If a capability is unavailable or blocked, immediately try the next valid option.
4. Never bypass authentication, permissions, platform policies, copyright or licensing controls.
5. Every production has an explicit state and machine-readable evidence.
6. `COMPLETE` is emitted only after final QA, successful publication, and publication verification.

## Pipeline

`brief -> script -> storyboard -> visual generation -> voice -> music -> foley/sfx -> mix -> edit -> subtitles -> thumbnail/metadata -> rights gate -> final render -> final QA -> publish -> publication verification -> analytics -> reach -> revenue`

## Integrations

- GitHub: source and reusable capability layer.
- YepCode: optional execution adapter/orchestration layer.
- YouTube/Meta/OTT: publishing adapters using official authorization flows.
- Local/open-source media and AI tools: preferred execution path where available.

## Important boundary

This service must not claim that an external capability ran successfully unless an execution result is actually returned. External credentials remain in secret stores/environment configuration and are never committed to the repository.
